# Техническое задание (ТЗ) на разработку программного продукта

## 1.  **Введение**

Программа «Синтаксический анализатор выдуманного языка» (далее – ПП) предназначена для автоматизированного лексического, синтаксического и семантического анализа исходного кода, написанного на учебном выдуманном языке программирования.

## 2.  **Основания для разработки**

Основанием для разработки является задание на практическую работу №1 по дисциплине «Тестирование программного обеспечения». Нормативная база: ГОСТ 19.201-78 «Техническое задание. Требования к содержанию и оформлению», ГОСТ 34.602-2020, а также формальная грамматика языка (Приложение А).

## 3.  **Назначение разработки**

Автоматическая проверка корректности исходного кода на соответствие формальной грамматике, выявление лексических, синтаксических и семантических ошибок с выводом подробных диагностических сообщений в консоль.

## 4.  **Требования к программе**
### 4.1.  **Функциональные требования:**

  - Разбиение входного текста на лексемы (ключевые слова, идентификаторы, числа, разделители, комментарии).
  - Проверка последовательности лексем на соответствие правилам грамматики (метод рекурсивного спуска).
  - Проверка семантических правил: переменная должна быть объявлена через ключевое слово dim перед использованием.

### 4.2.  **Надежность:**

При обнаружении ошибки программа должна выводить сообщение в консоль с указанием типа ошибки и завершать работу с ненулевым кодом возврата.

### 4.3.  **Условия эксплуатации:**
- ОС: Windows, Linux, macOS.
- Среда выполнения: интерпретатор Python 3.8 и выше.

### 4.5.  **Совместимость:**

Входные файлы с исходным кодом должны быть в текстовом формате с кодировкой UTF-8.

## 5.  **Требования к интерфейсу**

Консольный интерфейс. Запуск осуществляется путем передачи пути к файлу с исходным кодом в качестве аргумента командной строки.

При успешном анализе выводится сообщение: Синтаксический анализ пройден успешно. / Семантический анализ пройден.

При ошибке выводится сообщение в формате: ЛЕКСИЧЕСКАЯ ОШИБКА (строка N): ... или СИНТАКСИЧЕСКАЯ ОШИБКА (позиция M): ...

## 6.  **Критерии приемки**

- Успешный разбор 100% программ из предоставленного набора валидных тестов.
- Корректное завершение работы с кодом возврата 0 при отсутствии ошибок в коде.
- Корректное прерывание работы с кодом возврата 1 при наличии синтаксических или лексических ошибок.

## 7.  **Порядок запуска**
1.  Подготовьте файл с исходным кодом на выдуманном языке (например, test.txt) в кодировке UTF-8.
2.  Откройте терминал (командную строку) в директории с проектом.
3.  Выполните команду запуска, передав путь к файлу в качестве аргумента: python main.py test.txt

## 8.  **Интерпретация результатов**

**Успешный анализ:** В консоли последовательно появятся сообщения об успешном прохождении лексического, синтаксического и семантического этапов. Программа завершится с кодом 0.

**Ошибка анализа:** Программа выведет сообщение, начинающееся с ЛЕКСИЧЕСКАЯ ОШИБКА, СИНТАКСИЧЕСКАЯ ОШИБКА или СЕМАНТИЧЕСКАЯ ОШИБКА, содержащее номер строки или позиции, а также описание проблемы. Программа завершится с кодом 1.

## 9.  **Порядок контроля и приемки**

Тестирование методом «черного ящика», проводимое независимой командой (Команда Б) на основе набора тестовых сценариев. Проверка включает как позитивные сценарии (валидный код), так и негативные (код с преднамеренными ошибками).

## 10.  **Этапы и сроки разработки**

- Разработка модулей анализаторов: 3 рабочих дня.
- Внутреннее тестирование и отладка: 1 рабочий день.
- Внесение учебных дефектов и подготовка документации: 1 рабочий день.
